# Changelog

## [1.3.0] - 2026-03-15
### Added
- Modo full-page screenshot (página completa)
- Selector de viewport (mobile, tablet, desktop)
- Soporte para dark mode forzado

### Fixed
- Screenshots en blanco en sitios con lazy loading
- Timeout en páginas pesadas

### Improved
- Renderizado 50% más rápido con nuevo motor
- Mejor calidad de imagen (2x resolution)

- Formato WebP para menor tamaño

- Error 403 en sitios con protección Cloudflare
