# Changelog

## [3.1.0] - 2026-03-20
### Added
- Soporte para GPT-4o mini (más rápido, más barato)
- Modo streaming mejorado con markdown en tiempo real
- Contexto extendido a 128k tokens

### Fixed
- Respuestas truncadas en conversaciones largas
- Error de timeout en preguntas complejas

### Improved
- Latencia reducida 45% en primera respuesta
- Mejor formateo de código en respuestas
