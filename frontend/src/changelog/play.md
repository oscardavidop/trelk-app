# Changelog

## [2.3.0] - 2026-03-01
### Added
- Soporte para links de Spotify (tracks, playlists, albums)
- Cola de reproducción mejorada con drag & drop
- Visualización de carátula del álbum

### Fixed
- Audio cortado en canciones largas (+10min)
- Timeout en búsquedas lentas

### Improved
- Calidad de audio por defecto aumentada a 320kbps
- Respuesta 40% más rápida en búsquedas

---

## [2.2.0] - 2026-01-20
### Added
- Soporte para links de SoundCloud
- Modo repeat (loop de canción actual)

### Fixed
- Error al reproducir playlists con +50 canciones

---

## [2.1.0] - 2025-11-15
### Added
- Inline mode para búsqueda rápida
- Letras automáticas con /lyrics integrado

### Improved
- Detección automática de idioma en búsquedas

---

## [2.0.0] - 2026-01-15
### Added
- Reescritura completa del motor de reproducción
- Soporte multi-fuente (YouTube, Spotify, SoundCloud)
- Sistema de cola persistente

### Removed
- Motor legacy de descarga

## [1.0.0] - 2025-09-01
### Added

- Búsqueda y reproducción desde YouTube
